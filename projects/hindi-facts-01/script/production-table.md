## Audio bed (all synthesised, no licensed samples)

| Layer | Design |
|---|---|
| Kick | 58 Hz pitch-drop sine + click transient, 0.55 gain |
| Sub | Root note per 2-bar chord: Dm → B♭ → F → C (D minor, cinematic) |
| Pad | 3-voice detuned triangle+sine stack, 0.085 gain, slow LFO |
| Hats | High-passed noise, 0.10 gain on off-beats, 0.045 on 16ths |
| VO | 9 TTS clips placed on the cut grid, trimmed to ±10 ms |
| SFX | Whoosh (band-swept noise), impact (44 Hz boom + air), riser (noise + tone sweep), tick (2.4 kHz + 620 Hz) |
| Ducking | Music −5.5 dB under VO, SFX −3.5 dB (envelope-follower sidechain) |
| Master | BS.1770-4 integrated → **−14.0 LUFS**, ceiling **−1.9 dBTP** |

## Caption system

- Word-level timing derived from the VO energy envelope (HarfBuzz-shaped Devanagari, so matras and conjuncts never break).
- 3 words max per line, 22 characters max — nothing wraps.
- Spoken word turns **amber** and scales 1.06×; the rest stay white.
- Captions sit at y = 1,250 (1,420 in the ledger, 1,560 on the payoff) — inside x 84–996, above the Shorts UI band, with a bottom-scrim gradient for legibility.
